# Changelog

All notable project changes are documented here. The repository history remains the detailed record.

## Unreleased — Phase 0

- Established the public Open Video Converter project documentation.
- Recorded immutable historical upstream revisions, sampled fork findings, provenance boundaries, and UI behavior evidence.
- Published a proposed FFmpeg/ffprobe distribution evaluation and verification matrix.
- Recorded private visual-reference observations without publishing source images or historical assets.
- No application source, media binary, or release artifact has been added.

## Unreleased — Foundation

- Renamed the working project identity and repository to Open Video Converter while trademark permission remains pending.
- Added an original Swift/AppKit local-development foundation with file intake, drag-and-drop, queue state models, and an initial preset catalogue.
- Added local build/run and test workflows.
- Verified the foundation locally with three automated tests and a Debug app launch; no public binary has been released.
