# Roadmap

## Phase 0 — Research and plan

Historical analysis, fork comparison, licensing/branding/provenance review, FFmpeg strategy, UI record, architecture validation, test design, and approved implementation backlog.

## Phase 1 — Foundation

Create the macOS project, AppKit window/queue shell, ffprobe inspection abstraction, data-defined preset loading, fixtures, and development build policy.

## Phase 2 — Reliable conversion

Implement conversion planning, safe output management, FFmpeg execution, progress, errors, cancellation, serial batch behavior, and baseline generic/compatibility presets.

## Phase 3 — Product fidelity and modern presets

Refine the historical Miro experience, add reviewed Online, Devices, Editing, and Format families, introduce rotation tools, and verify Intel and Apple Silicon behavior.

## Phase 4 — Release readiness

Accessibility, failure recovery, privacy review, licensing notices, source availability, signing, notarization, release artifacts, checksums, and release notes. Experimental GitHub builds may precede this phase only under the documented alpha-release policy.

## Later exploration

Additional transforms, preset editing, translations, update mechanisms, and platform expansion are potential future work, not current commitments.
