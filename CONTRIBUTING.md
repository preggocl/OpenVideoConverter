# Contributing

Thank you for your interest in Miro Video Converter 4.

## Current phase

The project is in Phase 0. The focus is evidence-backed research and planning, not application implementation. Useful contributions include:

- Verified references to historic Miro behavior or source material.
- Fork comparisons with commit IDs and meaningful diffs.
- Public, authoritative platform media guidance with publication dates.
- FFmpeg build, licensing, packaging, and macOS distribution research.
- Accessibility observations about the original workflow.

Please avoid submitting ports, copied assets, bundled binaries, or large new feature implementations until the Phase 0 decisions are published.

## Evidence standard

Link claims to a stable source: a repository revision, path, commit, release, official document, or reproducible test. Separate observations from conclusions and identify uncertainty.

## Scope and style

- Preserve the product’s simple “add → choose → convert” intent.
- Do not assume rights to historical names, logos, icons, screenshots, or code.
- Do not introduce confidential material, credentials, media files, or generated build artifacts.
- Keep public documentation factual, respectful, and understandable to developers and users.

## Before opening a change

Discuss material changes through an issue first, particularly those affecting licensing, branding, FFmpeg configuration, supported codec claims, or the fundamental UI direction.
